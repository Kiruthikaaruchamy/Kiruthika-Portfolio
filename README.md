# Kiruthika Aruchamy — Data Analyst Portfolio

A responsive portfolio website showcasing analytics projects, technical skills, professional experience, and contact information.

## Built with
HTML, CSS, and vanilla JavaScript. No build step or dependencies required.

## Run locally
Open `index.html` in a browser.

## Deploy with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then Save.
4. Your site will be available at: https://kiruthikaaruchamy.github.io/Kiruthika-Portfolio/

## Portfolio sections
- About and professional summary
- Core skills and tools
- Selected analytics projects linked to their source repositories
- Professional experience and education
- Certifications
- Resume download and contact links
